# Integrations report errors (Sheets, Slides, DS)

> **Collection:** Customer Success
> **Last Modified:** 2023-04-20
> **Tags:** Andreea, data studio, google sheets, google sheets addon, integration, reporting, Slides add-on

---

When a client comes with a reporting error in the Data Studio (Looker), Sheets, or Slides, please ask the client to confirm the API token they used for that report (don’t assume it’s the main/owner one from under the Profile).



Also, this needs to be added to the task content if a task is required.
