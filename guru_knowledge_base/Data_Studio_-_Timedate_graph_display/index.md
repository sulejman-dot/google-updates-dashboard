# Data Studio - Time/date graph display 

> **Collection:** Customer Success
> **Last Modified:** 2020-05-13
> **Tags:** Ana, chart, data studio, rank flowchart

---

It seems that the standard Time display for Data studio if the month format (day 1 to day 30/31), even when the [Data range is a custom one](https://downloads.intercomcdn.com/i/o/208347486/55c98ebb816bfd07737dd6ba/2020-05-12_1430.png).

The display in the table can be changed from the Chart Style ([https://share.getcloudapp.com/o0ugKe4L](https://share.getcloudapp.com/o0ugKe4L)).
Under General, setting the Missing data to 'Line breaks' will no longer show a big drop to 0.
Under Axes, selecting the 'Reverse X-axis direction' will show the dates in a chronological order, April to May.
