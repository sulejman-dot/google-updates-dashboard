# Data Studio - Campaign connector - Daily visibility for groups

> **Collection:** Customer Success
> **Last Modified:** 2020-06-24
> **Tags:** Ana, connector, data studio

---

In the details of the parameters of this endpoint, the [Daily Visibility for groups is shown](https://share.getcloudapp.com/JruL1qBK).

To have the data for a specific group, when the connector is used, the name of the group has to be added there ([https://share.getcloudapp.com/yAuYr6Dz)](https://share.getcloudapp.com/yAuYr6Dz), in the Group name field and afterward to proceed in creating the report. 

Knowing for which group the report is made is up to the user. 



The explanation, design of it,  when the connector is made, the group name is added, we find that specific group by name, take the ID and add it to the call that brings the data. All the data/metrics from there (in the report) are for a specific group (or All keywords if the group name is left blank).
