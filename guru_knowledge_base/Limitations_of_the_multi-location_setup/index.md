# Limitations of the multi-location setup 

> **Collection:** Customer Success
> **Last Modified:** 2025-01-28
> **Tags:** api, google data studio, multi-location

---

Sublocations that are part of the umbrella campaign will **not **have access to traffic data (GA/GSC integrations), nor Forecasting. 



Looker and API will work to get campaign data (SVs and ranks), without traffic and forecast. 

The rank tracker endpoint can be used as long as the sublocation's campaign ID is used.
