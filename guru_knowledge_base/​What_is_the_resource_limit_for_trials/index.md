# ​What is the resource limit for trials?

> **Collection:** Customer Success
> **Last Modified:** 2023-05-16
> **Tags:** keyword limit, Maria, trial

---

The only limit for users during the trial period is up to 30.000 keywords for the entire account (pitching keywords aren't taken into account).

_It used to be 20K but we had a lot of trial accounts that added large campaigns (more than 100K keywords added in one day). So in order to reduce the load on the swarm that these trial campaigns were creating we reduced the maximum number of allowed keywords for trial accounts from to 30K_
