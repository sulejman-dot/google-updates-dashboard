# ​Data Studio - Conversion display in the report

> **Collection:** Customer Success
> **Last Modified:** 2020-05-05
> **Tags:** Ana, conversions, data studio, goals, settings

---

.The display of values is related to the selection of the Website Settings to Default Conversion type, where there are 2 options Goals and Ecommerce ([https://share.getcloudapp.com/xQuWzYx4](https://share.getcloudapp.com/xQuWzYx4))

For the correct data to be displayed in the Data Studio report, the following metrics should be selected:

- 
for Conversion Type _Goals_, select Goals and Goals rate ([https://share.getcloudapp.com/JrubGqp5](https://share.getcloudapp.com/JrubGqp5))

- 
for Conversion Type Ecommerce, select Conversion and Conversion rate
