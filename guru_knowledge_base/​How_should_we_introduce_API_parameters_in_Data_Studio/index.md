# ​How should we introduce API parameters in Data Studio?

> **Collection:** Customer Success
> **Last Modified:** 2019-03-05
> **Tags:** API call, connector, data studio, Mircea

---

Every connector in Data Studio represents a different API call from our API call list.

If you want more parameters than a call provides, a new connector must be made, with a separate call. Then you filter information in DS.
