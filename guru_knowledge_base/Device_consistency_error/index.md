# Device consistency error

> **Collection:** Customer Success
> **Last Modified:** 2019-06-07


---

They occur at significant differences between the mobile and the desktop ranks - one is in the top, another is on 99+.

 If the ‘bubble’ is red ([http://take.ms/zqdHA](http://take.ms/zqdHA)), you need to go check the list [here](https://app.seomonitor.com/smadmin/deviceConsistency).

1. 
Go to the Keyword page - [http://take.ms/SwU1C](http://take.ms/SwU1C).

1. 
Download SERP from the 99+ device - [http://take.ms/4j1tg](http://take.ms/4j1tg).

1. 
Search for the domain you are tracking, but disregard if it’s only in ads, videos, etc. - [http://take.ms/uNJxY](http://take.ms/uNJxY).

  1. 
If found (or the SERP page looks odd) >> Report to DEV >> sends task in Trello. [http://take.ms/RVlVP](http://take.ms/RVlVP) 

  1. 
If not found >> Check. [http://take.ms/RVlVP](http://take.ms/RVlVP) 



When all are checked, the ‘bubble’ turns green. And it should always be so. :)
