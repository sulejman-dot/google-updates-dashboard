# ​Can you have in the same Data Studio report data from 2 SEOmonitor campaigns?

> **Collection:** Customer Success
> **Last Modified:** 2019-08-14
> **Tags:** Ana, data studio

---

In Data Studio, 1 SEOmonitor campaign is considered one source. 

To have 2 sources of data, in the same report, these need to be blended and the blending has to be checked with Data Studio.
