# ​How many keywords can be added to the Brand group? And why can't I add a CSV with keywords there?

> **Collection:** Customer Success
> **Last Modified:** 2019-10-15
> **Tags:** Ana, brand, keywords, limit

---

There is no limit to the number of keywords that can be added to the Brand group.

If you are trying to add keywords ONLY in the Brand folder, via CSV you can't. In order to be able to do so (if they meet the criteria for Brand keywords of course), you need to have in the same CSV, also keywords that will go in other groups, besides the Brand one.
