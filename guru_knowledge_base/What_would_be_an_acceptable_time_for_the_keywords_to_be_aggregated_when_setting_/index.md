# What would be an acceptable time for the keywords to be aggregated when setting up a new campaign or adding new keywords to an existing one?

> **Collection:** Customer Success
> **Last Modified:** 2022-03-30
> **Tags:** acceptable time, aggregation, aggregation time, Delia, Ioana, new campaign, Rank Tracker

---

The aggregation process should not take longer than 30 minutes.
If new keywords added are aggregated in 30 minutes it's not a bug but if it takes longer, a task will be required.
