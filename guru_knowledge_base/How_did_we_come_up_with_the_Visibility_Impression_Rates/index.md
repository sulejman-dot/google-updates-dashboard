# How did we come up with the Visibility Impression Rates?

> **Collection:** Customer Success
> **Last Modified:** 2024-06-05
> **Tags:** Delia, impressions, Rank Tracker, visibility, Visibility Impression Rate, visibility performance

---

The Visibility metric is more of a scroll-depth analysis (so more rank-like than CTR-like): 
W_hat do I see if I don’t scroll, what do I see if I scroll once, and so on._

We've done an analysis on millions of keywords and the anonymized GSC data in our databases around 2020

It’s powerful when used as _relative_: Visibility is primarily made to be representative relative so in trends (self vs self) and comparisons (self vs competitors) to see current opportunities for growth.

__The absolute metric to look at would be the CTR (and the CTR-based "% of clicks on Organic results"). This is based on statistical data:__

· We have (for example) April’s Search Volume value (so not the 12-month average Search Volume)

· We have the Desktop and Mobile ranks

· We have the Google Search Console data and the average ranks from there

· We have the SERP features present in the corresponding pages.

_So we were able to conclude that: “if I have Maps/Places in the SERP, this would get me this many clicks for the #3 rank”._

Then, with all of these features and the corresponding data, we made the curve, which helped us estimate the remaining clicks on organic results. This then gives the impact in searches (so % out of the Search Volume).
