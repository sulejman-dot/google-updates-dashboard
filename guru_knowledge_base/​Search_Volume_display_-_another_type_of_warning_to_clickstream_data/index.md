# ​Search Volume display - another type of warning to clickstream data

> **Collection:** Customer Success
> **Last Modified:** 2020-05-12
> **Tags:** adwords, aggregated, Ana, clickstream, search volume, warning

---

To the clickstream data, the explainer can sometimes display this information _'We have identified that this keyword is now reported in _**_AdWords_**_ as being aggregated under _**_Main-keyword_**_, which gives it the wrong value: _**_?K monthly searches_**_ ?'_

This warning/explainer is shown when the search volume of a keywords increase or drops a lot, at once. In this case, an algorithm runs to detect if that keyword was aggregated under a Main keywords, and if so, the warning is shown.
