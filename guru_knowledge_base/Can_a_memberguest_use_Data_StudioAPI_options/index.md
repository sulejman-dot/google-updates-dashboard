# Can a member/guest use Data Studio/API options?

> **Collection:** Customer Success
> **Last Modified:** 2024-09-11
> **Tags:** api, API token, data studio, Delia, google data studio

---

Yes, they can. 

If they see a blank space under "User Profile," they can click on _regenerate_, and they will have the API token.

- Full [SEOmonitor API documentation](https://api-docs.seomonitor.com/#/)
