# Switch off traffic tracking for a campaign.

> **Collection:** Customer Success
> **Last Modified:** 2023-05-04
> **Tags:** disconnect traffic, Ioana, track traffic, traffic tracking

---

If a user wants to stop tracking traffic for a campaign and therefore stop paying the corresponding EUR9.99, they have to use the "Disconnect Forecast and Organic Traffic" option in the Campaign Setting sidebar, Connected Accounts tab.
[https://take.ms/frC2P](https://take.ms/frC2P)

Bear in mind that this is only available for the newer accounts with the "new pricing"  type of subscription.

The users don't have the option to disconnect the last GSC profile and GA by themselves. 
But note that **disconnecting the profiles does not equal disabling traffic tracking.**

Also, **if the Organic Traffic and Forecast are disabled, we won't pull data for that website however, we do not disconnect the profiles in case you want to revert.
**Currently, the display is to show the profiles connected, which might be misleading.
