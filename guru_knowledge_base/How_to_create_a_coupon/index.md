# How to create a coupon

> **Collection:** Customer Success
> **Last Modified:** 2024-09-13
> **Tags:** chargebee, coupon, create coupon, new coupon, next billing

---

S​elect the client you wish to add a coupon to →  the subscription must still be active .

I. I​f there is an **existing** coupon, you might want to **first remove it** before adding another, in that case:

1. Go to [Change subscription](https://take.ms/UTSEO)
1. Make sure all information is filled in.

O​nce step 2 is completed go to→  [View details](https://take.ms/w38Ta) →  [Remove](https://take.ms/LWcXb) + Remove

II. Create the **new coupon**

1. Go to Product Catalog → [Coupons](https://take.ms/tB4R1) (Open in a New browser window)
1. Upper right corner → [Create](https://take.ms/nWOUe) coupon
1. [Name](https://take.ms/5God4) the coupon so you can easily find it later (get UserID from smadmin, get timestamp through [here](https://www.epochconverter.com/)) + ID will be created automatically.
1. get timestamp through [here](https://www.epochconverter.com/)
1. fill in details [here](https://take.ms/OeKfM)
1. Select Discount Type → Always will be [Fixed ](https://take.ms/7cZL1)
1. Keep in mind the currency set for this account, select accordingly 
1. Select the amount you want to apply the coupon for
1. Apply on → Always [Invoice Amount](https://take.ms/uvol8)
1. Duration Type → usually limited to the number of months you apply it to
1. Validity refers to the period this coupon will be available to be applied to a subscription **NOT** for the validity period offered on the coupon
1. Maximum Redemptions → always 1
1. Save + Check if the coupon was created

III. After the coupon was created it needs to be added to the subscription

1. Go to → [Change Subscription](https://take.ms/qhuzI)
1. Add [coupon](https://take.ms/YrCMn)
1. Select coupon ID [here](https://take.ms/K3XM8)  + Add coupon
1. Apply changes immediately
1. Add to [unbilled charges](https://take.ms/TVAbm)
1. Change subscription
1. Preview changes + Confirm 
1. Double check on  [Customer Details](https://take.ms/YDDRa) if the coupon was added successfully

→ In case you with to change Next Billing to an earlier date

1. Subscription → [View Details](https://monosnap.com/file/EM4k2bodkqJtuaH7VsOoowTKx2byq0)
1. Go [here](https://take.ms/yIwOv) to Change Next Billing 
1. Select [Date](https://take.ms/Eg9bW), place Comment (initials) + Change→ Confirm
1. Check under Invoices if the new invoice was generated
1. If the invoice has amount 0, it means that our coupon was applied successfully
