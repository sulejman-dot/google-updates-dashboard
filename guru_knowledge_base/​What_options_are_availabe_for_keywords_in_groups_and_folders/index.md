# ​What options are availabe for keywords in groups and folders?

> **Collection:** Customer Success
> **Last Modified:** 2019-02-21
> **Tags:** move keywords, options for keywords

---

In groups, there are 4 options - [http://take.ms/Ia8jY](http://take.ms/Ia8jY)

1. 
remove from group

1. 
add keywords to group

1. 
move keywords

1. 
delete keywords


In folders, 2 options are available - [http://take.ms/4QDaz](http://take.ms/4QDaz) - the reason is that a keyword belongs to a group, not to a folder; the folder is the tag of multiple groups; the script wouldn't know in which groups a certan keyword should remain and in which not; the only possible outcome would be to remove/move all those keywords, but that is only a feature request at the moment, since the product was conceived with a different purpose

1. 
add keywords to group (you then select the desired group)

1. 
delete keywords


Special mentions:

- 
a more recent addition -   `p{Mn}` - “\p{Mn} or \p{Non_Spacing_Mark}: a character intended to be combined with another character without taking up extra space (e.g. accents, umlauts, etc.).”

- 
foreign characters such as Arabic fall under the \p{L}  code
