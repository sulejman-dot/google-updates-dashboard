# When do we see Average Conversion Rate & Average Conversion Value in Forecast?

> **Collection:** Customer Success
> **Last Modified:** 2019-03-26
> **Tags:** conversions, e-commerce, forecast, forecasting, goals, Ioana, transactions

---

In order for these 2 fields to be available (they are also editable) there has to be Conversions or respectively Transactions info available in Analytics, for the specific website, according to the Default conversion type selected in Website settings, in the  SEOmonitor account.

Where to find the 2 fields in Forecast [https://take.ms/TtrBA](https://take.ms/TtrBA)
