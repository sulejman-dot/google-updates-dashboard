# Update Forecast and Update Target

> **Collection:** Customer Success
> **Last Modified:** 2019-09-19
> **Tags:** Ana, forecast

---

Update Forecast is done for what you selected in forecast, if it's all keywords then for all keywords, it depends on the options in the left sidebar.
This action will keep the scenario as a Draft (with your selected target for all keywords/specific groups).



Update Target is not equivalent with Set target
