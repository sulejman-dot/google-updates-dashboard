# When is mobile traffic (Mobile Searches) and YoY trends populated for a new project?

> **Last Modified:** 2020-12-15
> **Tags:** Ana, Mircea, mobile search, YOY

**expert - sterge cardul dublat din Project* 

YOY trends will show starting after the 1st month of subscription, when there will be 13 months available of Search Volume Data on those keywords.

For pitching projects, in SEO Campaign, we show YoY only after connecting the GA (as shown in the tooltip), except in Forecast area where we do display it, for Topics market.

**Mobile traffic** should be populated within a couple of hours from the start of the keyword processing, but only if GSC is connected.

If the GSC was never connected, the display should show N/A.

While values are updated on the 24th every month.
