# ​How many "other owned media" can be added to the platform?

> **Collection:** Customer Success
> **Last Modified:** 2025-06-16
> **Tags:** Campaign Settings, Rank Tracker, tracking

---

NOTE: This was proposed to be increased.


Until a future development, only one other tracked media can be added to the system.

For http/https variations, there is no need for another media to be added, we just require a corresponding GSC profile to be authorized.
