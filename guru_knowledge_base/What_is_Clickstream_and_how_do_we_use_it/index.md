# What is Clickstream and how do we use it?

> **Collection:** Customer Success
> **Last Modified:** 2020-11-04
> **Tags:** adwords, clickstream, historical search volumes

---

**Clickstream = a record of a user's activity on the web as represented by the sequence of links they click on (including every site and the pages visited on that site, how long the user was on a page, any followed newsgroups, any email addresses in contact with the user).**

The **clickstream** analysis is the process of collecting, analyzing and reporting aggregate data. Since
Clickstream data is becoming increasingly valuable to Internet marketers and advertisers, so the sessions are monitored from behind the curtains, data is gathered, stored and eventually even sold.

Places where we have used clickstream or a reference to it:

1. 
**When Adwords shows 0
Search Volumes** (e.g. for 'dangerous' terms) - In such cases, we'll use **clickstream **data, which is less accurate but better than 0. When clickstream data is used for search volume estimate, [a warning icon](https://take.ms/lhsEV) is placed next to it with details in the [tooltip](https://take.ms/SLq3C). (NOT for customer - initial clickstream is SERPstat, when no SERPstat info, 2nd clickstream source is GSC; the GSC volumes should also be marked with the exclamation point)
the rule is: if you don't have SV in adwords -> go to SERPstat if there aren't in  -> go to GSC


1. 
Our **Keyword database **was started from **clickstream** data, then calibrated through a thorough process

1. 
We use it in conversations with customers when we want to avoid advertising a competitor (as in bullet no.1 , where we never pronounce SERPstat, we only say clickstream to the customer)



Internal note - We don't use Jumpshot data
