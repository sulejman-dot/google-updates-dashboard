# ​Can we import historical data for competitors?

> **Collection:** Customer Success
> **Last Modified:** 2021-04-29
> **Tags:** competitor rank, historical data, migrating

---

If a client migrates to us, they can export those ranks and whenever we’ll offer that option, they’ll be able to push them into our platform.

From GA & GSC we take traffic data and we can go up to 1 year back starting the date the campaign was added.

We pull 1 month back by default, the other 11 months you can request in the Traffic section (provided the profiles hold data so far back).
