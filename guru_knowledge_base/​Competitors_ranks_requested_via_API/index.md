# ​Competitors ranks requested via API

> **Collection:** Customer Success
> **Last Modified:** 2024-09-11
> **Tags:** Ana, API call, competitors

---

Started from the API call: [GET](https://docs.seomonitor.com/api/v1#!/Compare/get_compare_keywords_site_id_start_date_end_date_competitors_group_id) [/compare/keywords/{site_id}/{start_date}/{end_date}/{competitors}/{group_id}](https://docs.seomonitor.com/api/v1#!/Compare/get_compare_keywords_site_id_start_date_end_date_competitors_group_id)

How the actual ranks are displayed: 

- If your website is added as a competitor: the API call will return the exact rank value up to rank 98, and a higher value will be returned as 99+
- If the website is one of your competitors: the API call return the exact rank value up to rank 20, and a higher value will be returned as 20+
