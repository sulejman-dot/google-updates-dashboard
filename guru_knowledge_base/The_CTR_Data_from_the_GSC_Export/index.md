# The CTR Data from the GSC Export

> **Collection:** Customer Success
> **Last Modified:** 2021-08-05
> **Tags:** CTR, Delia, export, gsc export, organic traffic, traffic

---

This data from the GSC Exports (both exports, from the interface and the ones we have in admin) is an average for the selected timeframe, provided by GSC.

If you select a day's worth of data, it will show you the CTR for that date, if you select a longer period, it's an average.
