Guidelines for using this tool.

1. Check issue ([http://take.ms/Kto3B](http://take.ms/Kto3B))
2. Add label/tag (bug, feature, improvement, support) in US [http://take.ms/UtePm](http://take.ms/UtePm)
3. Assign self or another CS [http://take.ms/WcXpi](http://take.ms/WcXpi)
4. Create trello task, if needed 
5. Add task link in US
6. Inform the client that we're handling their request/issue
7. Add conversation link in US [http://take.ms/gjIzN](http://take.ms/gjIzN)
8. Close usersnap
9. Inform the client of completion of the task once done
