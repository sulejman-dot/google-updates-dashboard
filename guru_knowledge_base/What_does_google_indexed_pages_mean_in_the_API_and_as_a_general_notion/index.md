# What does "google_indexed_pages" mean in the API  and as a general notion?

> **Collection:** Customer Success
> **Last Modified:** 2020-06-09
> **Tags:** api, google indexed page, index, indexed page, Ioana

---

**As a general notion **- The number of pages indexed by Google for that specific search

Indexed pages are the pages of a website that a search engine has visited, analyzed and added to its database of web pages. Pages are indexed either because the website owner requested the search engine to index web pages or through the discovery of web pages by the search engine bot through links to those pages.

**In the API call **- if it exists, it represents indexed pages for that keyword but it will most probably become deprecated and return null values (according to Marius [https://take.ms/pSlyD](https://take.ms/pSlyD) [https://take.ms/dWLvo) ](https://take.ms/dWLvo)
