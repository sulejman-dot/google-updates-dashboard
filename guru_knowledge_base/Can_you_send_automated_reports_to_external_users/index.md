# Can you send automated reports to external users?

> **Collection:** Customer Success
> **Last Modified:** 2018-05-31


---

Currently (31st May 2018), only people added as users (including view-only status), can receive the automated scheduled reports.
But on the other hand, they don't need to log in the app, in order to receive them (this is a requirement only for the Custom reports). 

So you can simply add them as View-only users and define the frequency and areas you want included in the scheduled reports.  

I've set this idea as a feature request (I'll check the card again in 6 months, to see if the feature has been done and if so, update the article and delete the card).
