# ​How do we read aggregations in Topics?

> **Collection:** Customer Success
> **Last Modified:** 2019-04-17
> **Tags:** aggregation, Mircea, topics

---

All variations will be shown, no matter if children/parents - [http://take.ms/9IhbA](http://take.ms/9IhbA)

In order to see the parent, check for the underlined word - [http://take.ms/vx8pV](http://take.ms/vx8pV)

If there are no underlined words, the original one is the parent.
