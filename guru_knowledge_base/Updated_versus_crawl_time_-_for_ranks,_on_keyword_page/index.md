# "Updated" versus "crawl time" - for ranks, on keyword page

> **Collection:** Customer Success
> **Last Modified:** 2020-02-26
> **Tags:** crawl time, crawling, Katty, keyword page, ranks, updated

---

**INFO ON THIS CARD IS FOR CS KNOWLEDGE ONLY AND IT WILL NOT BE SHARED WITH THE USERS**

**Updated** ([https://take.ms/9WTAq](https://take.ms/9WTAq)) - is for the users and shows the official time when the update should happen

**Crawl time (**[https://take.ms/GKQQz](https://take.ms/GKQQz))** **- is for master pass and shows the real time of the crawl. Crawl time can be both before and after the Updated. 

**Tech should be notified if crawl time is older than 1 week.**

But bear in mind that there are some specific cases where the crawl is made less often (most common every 3 days), such as:

- 
close variations

- 
latest rank 99+

- 
search volume <= 100

- 
brand keywords

- 
swarm doesn't cover for the daily crawl need (for various reasons, resources are not enough for all keywords to be processed on time)
