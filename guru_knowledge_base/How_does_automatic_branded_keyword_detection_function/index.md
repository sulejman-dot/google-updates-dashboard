# How does automatic branded keyword detection function?

> **Collection:** Customer Success
> **Last Modified:** 2019-08-28
> **Tags:** brand detection, Mircea

---

**What it is - **​The setting 'automatic branded keyword detection' is an admin option in Website Settings - [http://take.ms/TrWbx](http://take.ms/TrWbx)

**Activation - **It can be activated/deactivated only manually, in Website Settings, and **only with Madalina's approval.**

**Signalling this special setting** -  [http://take.ms/7ksi6](http://take.ms/7ksi6) 

**Effects** - no brand words will reach the Brand folder automatically + client can unmark as brand any keyword in that folder
