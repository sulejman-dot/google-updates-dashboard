1. 
When adding any URL to [https://trends.seomonitor.com](https://trends.seomonitor.com), we don't change it in the upper box, but we copy only the domain in the lower box ([https://take.ms/4DOHN)](https://take.ms/4DOHN).


We remove anything besides the main domain (http, www, any subdomain or folder of the website). 

e.g.  [https://www.m.vodafone.co.uk/network/5g/why-vodafone](https://www.m.vodafone.co.uk/network/5g/why-vodafone) will become [vodafone.co.uk](http://vodafone.co.uk/). 

1. 
The Search Volume you see in Adwords is not relevant, since currently it shows you the estimated data (as our Adwords account, where CS has access, is not sufficiently 'mature' to show you exact data). The tool takes the data from another account, which offers us the exact Search Volume of the keywords.

1. 
When you see keywords with this display [https://take.ms/K4TJAl](https://take.ms/K4TJAl), that is normal; if last year it had no Search Volume and now it does, we can't calculate a percentage in growth (from 0 to 100 let's say).  We kept such keywords in the list, so that the user can see these newcomers, which are relevant to its business.
