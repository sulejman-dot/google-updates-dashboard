# What and where to check whenever we see traffic drops?

> **Collection:** Customer Success
> **Last Modified:** 2018-11-27
> **Tags:** traffic

---

We usually notice traffic drops in the SEO Campaign section ([http://take.ms/qCVnq](http://take.ms/qCVnq)), but in order to properly check if there's a problem there are a few steps to follow:

- 
check how the distribution looks like in the Organic Traffic section --> split the brand/non brand to see if there's something happening with the brand: [http://take.ms/etfRe](http://take.ms/etfRe)

- 
Select the date prior to the drop in the calendar, go to the Landing Page view and sort the traffic data by Visits, to see which LPs get most visits.

- 
Select the day of the drop in the calendar and check which LPs get most visits

- 
Export data from GA via API (use the 'i' button), for both of the dates (prior and after the drop) to see how the Landing Pages look like and how they have changed. If the LPs look different, there have been changes in GA and GSC doesn't acknowledge them just yet.
