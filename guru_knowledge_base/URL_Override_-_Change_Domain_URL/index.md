# URL Override - Change Domain URL

> **Collection:** Customer Success
> **Last Modified:** 2021-06-16


---

Change domain URL has now been updated to URL Override which can be found in the campaign settings under Admin Options. ONLY FOR ADMIN USERS/MASTER PASS

The change will add an annotation on the graph and also notify when the update has occur. 

At this point and time the "i" does not reflect the correct information from the dictionary and should not be taken into consideration (26th Aug)

This option is to be used no matter the reason why the URL has to be updated.
