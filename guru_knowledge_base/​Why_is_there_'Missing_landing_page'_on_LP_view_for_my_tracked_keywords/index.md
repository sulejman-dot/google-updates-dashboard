# ​Why is there 'Missing landing page' on LP view for my tracked keywords?

> **Collection:** Customer Success
> **Last Modified:** 2019-06-28
> **Tags:** landing page, Maria, Mircea, missing pages, rank 99+, warning

---

You see 'Missing landing page' for some keywords with 99+ ranks - (like in this example [https://take.ms/MbDEN](https://take.ms/MbDEN)). 

Since when we did the crawl we found no landing page that contains the domain's name in top 100, we continue the search even further and when we still can't identify an indexed page for them, in Google, we display this message.

Usually the tracked keywords in this situation, have this warning message when you are on keywords view - [https://take.ms/hzxxc](https://take.ms/hzxxc).

Thus, you can obtain such results by filtering according to warnings --> no relevant pages. The shown results will always have a yellow info box.
