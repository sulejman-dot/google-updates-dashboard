# What traffic do we consider if you connect a folder/subfolder Analytics view to a campaign where you're tracking the main domain?

> **Collection:** Customer Success
> **Last Modified:** 2022-01-27
> **Tags:** analytics, Delia, folder, forecast, Forecast configuration, forecasting, forecasting algorithm, inertial traffic, main domain, organic traffic, subfolder, traffic

---

**We pull the data for whatever Analytics profile is connected, if it's for the main domain, we take that traffic into account, if it's for a folder/subfolder we get the traffic for that specific folder/subfolder.

The same rule applies for the Inertial Traffic plotted in the Forecast.**
