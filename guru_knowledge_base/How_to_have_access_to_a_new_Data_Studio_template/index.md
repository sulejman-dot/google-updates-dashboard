# How to have access to a new Data Studio template

> **Collection:** Customer Success
> **Last Modified:** 2020-11-25
> **Tags:** connector, data studio, Ioana, template

---

In order to see a newly added template in one of our Data Studio connectors (we already had for Forecast and we recently added for Organic Traffic) you would have to revoke the access for that specific connector and then reconnect it, as the update won't be made automatically while the connector is "functioning".
