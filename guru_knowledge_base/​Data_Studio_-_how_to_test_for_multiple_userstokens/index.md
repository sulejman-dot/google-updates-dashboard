# ​Data Studio -  how to test for multiple users/tokens

> **Collection:** Customer Success
> **Last Modified:** 2020-04-28
> **Tags:** Ana, API token, data studio

---

In case tests are needed for multiple users with different API tokens, the only way to change the API token before a new request is to Revoke access from the Connectors List, in Data Studio ([https://share.getcloudapp.com/2NuX0Bvb)](https://share.getcloudapp.com/2NuX0Bvb). 

This option is not valid if you are accessing the connector directly, from our detailed task ([https://share.clickup.com/p/h/22gqp-533/376a4e7021b854d)](https://share.clickup.com/p/h/22gqp-533/376a4e7021b854d).
