# What position in the target rank do we take into consideration for the CTR value?

> **Collection:** Customer Success
> **Last Modified:** 2021-11-05
> **Tags:** CTR, Delia, forecast, forecasting, target rank

---

We don't consider just a certain position as the CTR value is an average that takes into consideration the ranks and the SERP features combinations for all the keywords included in the Forecast.
