**Types of articles:**

1. 
feature definition / how it works / FAQ (scurt): explanations, algorithms, metrics 

1. 
how to use it: steps, guide, actual functionality (clicks, hovers, etc)

1. 
use case: how to use it practically, how to get insights (understanding)


Examples for the 3 above on a feature: - BCB:

1. 
what it is, how we do it;

1. 
how to set a target;

1. 
how to win pitches.


### 

### **General guidelines**

- 
short, concise, clear;

- 
structure, structura, capitalize;

- 
first to understand the "storyline", create the context;

- 
**no fluff**: _can we do without this?_ qualifiers, filler phrases, etc.

- 
to be malicious with the competitors, to an extent :D

- 
_like we answer to a client, in a medium email, instead of conversational_;

- 
the articles have feedback! :D

- 
the more the better, so an **Operator** can do the job without us.


### **Screenshots**

- 
clear, with arrows, etc;

- 
choose the positive ones (more green than red);

- 
choose the ones with full data: VS, traffic, etc;

- 
use _inspect element_, if needed;

- 
use **large** accounts: upswing (if we don't need kws - because they are in Romanian) or shopify, made, etc.

- 
the price should always have this form: €x/month


### **BEGINING **

- 
the first paragraphs must keep them interested, not to be bored;

- 
even if we like it, do no make the _intrigue_ very long;

- 
what is the pain point?


### **THE END**

1. 
for the first type >> as logical as possible

1. 
for second type >> "what's next" links;

1. 
for third type. >> either to "related" or to what _we want_ them to read or to the catchy ones, so they'd read more.


>> we leave the user create by their own the necessary knowledge, if we manage to captivate them to read more articles 



### Updating articles

Whenever you have to update an article, please follow these 3 steps:

1. 
Create a document in Google sheets in this folder and start writing. After finishing, inform the Manager to review it.

1. 
After receiving the feedback and implementing it, update the article in Guru.

1. 
After updating the Guru card, you can now also update the article in Intercom which goes public.


Never update directly the Intercom articles!
