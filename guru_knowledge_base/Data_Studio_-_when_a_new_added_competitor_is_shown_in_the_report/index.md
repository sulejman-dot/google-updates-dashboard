# Data Studio - when a new added competitor is shown in the report?

> **Collection:** Customer Success
> **Last Modified:** 2020-09-17
> **Tags:** Ana, Competition, competitors, data studio

---

If there are no competitors added in the input, the report will show all the competitors from the app. 

The call is done each time the retrieve call is done (retrieve call can be done at refresh page or a new report). 

So, it should appear shortly after being added.
