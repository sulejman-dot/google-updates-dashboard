# Desired URL

> **Collection:** Customer Success
> **Last Modified:** 2021-07-06
> **Tags:** desired URL, desired URL icon, icon, Ioana, URL

---

Gives users the option to set an URL they wish a certain keyword to rank for so they can keep track of the achievement.
Up until the keyword starts ranking for that page, the app will attach a small heart to the Page icon.
