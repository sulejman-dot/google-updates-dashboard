_The categories above come from the below list, but we need to corelate them:_

The Brand categorization is based on **site_links properties, **depending on the results of the first positions in the SERP. In Topics we only display keywords with site_links<2

- 
**BRANDS**

- 
**site_links = 2 **- the first result contains links with descriptions (big format) below the initial description of the link [https://api.monosnap.com/rpc/file/download?id=Wxy78VFwWco5SntYe3UtzaYJlaDgUJ](https://api.monosnap.com/rpc/file/download?id=Wxy78VFwWco5SntYe3UtzaYJlaDgUJ)

- 
**site_links = 3** - the first 4 positions belong to the same domain [https://api.monosnap.com/rpc/file/download?id=VjVAyJLdYWQs3pPdZm05t0w5xhDMpa](https://api.monosnap.com/rpc/file/download?id=VjVAyJLdYWQs3pPdZm05t0w5xhDMpa)

- 
**site_links = 4** - the keyword phrase contains a keyword with site_links 2, examples: "minifrigider emag" or "raiffeisen carduri"

- 
**site_links = 5 **- the first 3 results belong to the same domain, while the 4th is a  Knowledge Graph

- 
**site_links** **= 6** - the keyword has a Knowledge Graph of types Company or Video Game 

- 
**site_links = 7** - keyword has site_links = 1 and first  2 results belong to same domain 




The non-brand types:

- 
**NOT BRANDS**

- 
**site_links = 0** - first result only contains title and description, nothing else [https://api.monosnap.com/rpc/file/download?id=7gYSJS9Ni09rbGDCECF8Jb8CGHSBIc](https://api.monosnap.com/rpc/file/download?id=7gYSJS9Ni09rbGDCECF8Jb8CGHSBIc)

- 
**site_links = 1** - first result contains small links under the description[ https://api.monosnap.com/rpc/file/download?id=uypFmvYpTwKPm7kvxzH3n1vyT6OAMS](https://api.monosnap.com/rpc/file/download?id=uypFmvYpTwKPm7kvxzH3n1vyT6OAMS)

- 
**SPECIAL NOT BRANDS**

- 
**site_links = -2** - it's a keyword with site_links=2 but the first link is not http://homepage.tld/ , or [http://homepage.tld/[de](http://homepage.tld/%5B2)]/ or [http://domain.tld/[ch]-[de]/](http://domain.tld/%5B2litere%5D-%5B2litere%5D/) - these are usually keywords designating products such as macbook pro, samsung galaxy, placa de baza asus, etc. and exceptions such as  "subliminal dex", "bucuresti iasi km", "cinema cluj", "facebook ajutor".
