# New subscription (wire transfer)

> **Collection:** Customer Success
> **Last Modified:** 2019-06-06
> **Tags:** Ana

---

Step 1: Go to [https://seomonitor-eur.chargebee.com/plans](https://seomonitor-eur.chargebee.com/plans) (Product catalog)

Step 2: Select “Plans” -> “Create new plan” ([https://take.ms/MXwcgY](https://take.ms/MXwcgY))

Step 3: [http://take.ms/NbPj2](http://take.ms/NbPj2)

Step 4: Go to [https://app.seomonitor.com/smadmin/subscriptionPackages](https://app.seomonitor.com/smadmin/subscriptionPackages) -> Add new subscription package -> [http://take.ms/BrtqB](http://take.ms/BrtqB)

Step 5: Go to [https://seomonitor-eur.chargebee.com/subscriptions](https://seomonitor-eur.chargebee.com/subscriptions) -> Create new subscription ([https://take.ms/fSgCGy](https://take.ms/fSgCGy)) -> [http://take.ms/O6y18](http://take.ms/O6y18)

Note: If you need to make changes to the package, you need to create a new one and reallocate it to the existing subscription (changes to the existing package do not apply to the subscription where it is associated) -> [http://take.ms/Cgmjl](http://take.ms/Cgmjl)
