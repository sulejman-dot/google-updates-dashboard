# VS impact numbers /per keyword from API 

> **Collection:** Customer Success
> **Last Modified:** 2019-06-07
> **Tags:** Ana, api, endpoint, keyword data, Mircea, VS impact

---

It refers to the reference frame for the numbers indicating VS impact/per keyword ([http://take.ms/a89Sd](http://take.ms/a89Sd)), from the API keyword data endpoint [https://docs.seomonitor.com/api/v1/#!/Keyword_Data/get_keyword_data_site_id_date_start_date_end](https://docs.seomonitor.com/api/v1/#!/Keyword_Data/get_keyword_data_site_id_date_start_date_end)

For the keyword level, it is about the rank change and the impact it had on impressions won or lost. So the number is the estimated number of impressions lost or won based on search volume and rank change.

For the group level, that number is the number of impressions won or lost. It translates the Visibility Change from a percentage in actual impressions. To put it simply is [Visibility Change] (%) * [Total Search Volume] of the group.
