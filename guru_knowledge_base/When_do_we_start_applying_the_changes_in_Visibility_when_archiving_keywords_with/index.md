# When do we start applying the changes in Visibility when archiving keywords with the option to "not recalculate retroactively"?

> **Collection:** Customer Success
> **Last Modified:** 2023-10-18
> **Tags:** Andreea, archiving keywords, historical visibility, visibility performance

---

It is intended behavior to preserve the current date's Visibility and apply the change from tomorrow onwards when you archive keywords and select "**NOT to recalculate**" the Visibility retroactively:
