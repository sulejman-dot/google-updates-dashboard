# ​Can we display split data based on the country with the most traffic? 

> **Collection:** Customer Success
> **Last Modified:** 2019-06-24
> **Tags:** Ana, traffic

---

It isn't possible to have the traffic split for 2 countries in the same campaign, after it was set up. 

Even so, there is a workaround. 
You can select the traffic filter when the GA profile is connected ([https://take.ms/EEhF3](https://take.ms/EEhF3)). 
And the traffic filtering option is activated when a localized campaign is selected, you can add a separate campaign and select it localized (even as a country: [https://take.ms/4k3Nr](https://take.ms/4k3Nr)).
