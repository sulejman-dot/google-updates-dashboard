# ​Can the VS be recalculated for a recalibrated SV period?

> **Collection:** Customer Success
> **Last Modified:** 2020-04-23
> **Tags:** Ana, calibrated, search volume, visibility score

---

If the Search Volume data was recalibrated an annotation will appear on the graph and the Visibility Score will take into calculation the new data. 

In case the data is reverted to the average Search Volume data, the Visibility Score cannot be changed for the timeframe of recalibrated SV data, and see the timeframe using the annotations on the graph.  



Covid-19 calibration info: [https://help.seomonitor.com/en/articles/3923882-search-volumes-after-covid-19](https://help.seomonitor.com/en/articles/3923882-search-volumes-after-covid-19)
