# ​Can we check if data is sent, via API, to a client? 

> **Collection:** Customer Success
> **Last Modified:** 2024-09-11
> **Tags:** Ana, API call

---

Yes, we can when the following message is displayed to the client: _"This organization access has been disabled or quota/rate limit is exceeded, please contact your API administrator"_.


We need:

- full details of one of their request: endpoint, parameters, API token (or the user confirmation of who the API token is used)
- task in Maintenance



[SEOmonitor API documentation](https://api-docs.seomonitor.com/#/)
