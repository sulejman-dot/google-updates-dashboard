# Can Regex be added to the Brand rule?

> **Collection:** Customer Success
> **Last Modified:** 2021-05-27
> **Tags:** brand rule, Ioana, regex

---

NO

It would be pointless because when the words are added with coma in the Brand rule, the algorithm does the same thing, match all keywords that include each of them.

Regex example
.*universal std.*|.*versal sts.*|.*versal srand.*|.*universla stand.*|.*tandard uni.*|.*versal atan.*|.*versal stran.*|.*vesal stan.*|.*versal stn.*|.*versial st.*|.*versl st.*|.*versa standard.*|.*univeral standard.*|.*united standard.*|.*ersal sta.*|.*erdal sta.*|.*universalstandard.*|.*universal.standard.*|.*universalstandard.*|us .*|.*geneva.*|.*kanda.*|.*fit liberty.*
