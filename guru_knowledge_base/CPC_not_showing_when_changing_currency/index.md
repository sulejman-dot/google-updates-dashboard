# CPC not showing when changing currency

> **Collection:** Customer Success
> **Last Modified:** 2020-11-06
> **Tags:** account settings, CPC, currency, Delia, seo campaign

---

When you change the AdWords currency, sometimes you might not see CPC for keywords in manage.
That's only because it recalculates it and if you refresh the page a few times, they will show. (that's how it's intended)
