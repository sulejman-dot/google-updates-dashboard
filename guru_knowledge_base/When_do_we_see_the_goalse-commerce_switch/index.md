# When do we see the goals/e-commerce switch?

> **Collection:** Customer Success
> **Last Modified:** 2019-03-26
> **Tags:** conversions, e-commerce, goals, Ioana, Mircea, switch, transactions

---

- 
​When 'Goals' is set in settings, no switch is available. 

- 
When `Default Conversion type` is set as "eCommerce" we have the switch available.


This is the switch -  http://take.ms/5fMhN

The default is chosen when adding the site and will be Ecommerce if the associated GA profile has eCommerce enabled. The default can be overwritten through Settings.
