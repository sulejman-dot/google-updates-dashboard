# How does Difficulty show in the API

> **Collection:** Customer Success
> **Last Modified:** 2022-09-09
> **Tags:** api, difficulty, display

---

In SEOmonitor's interface, the Keyword Difficulty  is displayed with ratings - Easy, Medium or Hard - [https://take.ms/ctLjr](https://take.ms/ctLjr)

Whereas in the API it comes as numbers - [https://take.ms/NQ9tZ](https://take.ms/NQ9tZ)

1  = Easy

2 = Medium

3 = Hard
