# Monthly to yearly subscription

> **Collection:** Customer Success
> **Last Modified:** 2019-11-20
> **Tags:** Ana

---

Step 1: Go to Chargebee >> Plans (Product catalog) >> [Addons](https://seomonitor-eur.chargebee.com/addons) >> Create a new addon ([https://take.ms/uxtT0n](https://take.ms/uxtT0n))

Step 2: The addon should have the following format - yearly_userid_nowebsites_nokwds (the user id is found in info [http://take.ms/U2AW3](http://take.ms/U2AW3)): if the resources are 1 website and 300 keywords, the addon will have the following format: **yearly_26764_1_300** ([http://take.ms/sXeuL](http://take.ms/sXeuL))

Step 3: Change the subscription - the plan is SEOmonitor Subscription Annual + the Addon that was created -> [http://take.ms/OkNic](http://take.ms/OkNic)

Note: Similarly, the yearly to monthly switch has to have a PLAN created, and the following format: seomonitor-flexible-plan-uid-id-currency (for the above case is **seomonitor-flexible-plan-uid-26764-eur )**



PS: when the invoice is generated, it is recommended to check that user's OrderID is a match with the one displayed in Bossulica.
