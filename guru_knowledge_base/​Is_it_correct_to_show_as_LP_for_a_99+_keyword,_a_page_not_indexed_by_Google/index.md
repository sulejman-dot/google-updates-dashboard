# ​Is it correct to show as LP for a 99+ keyword, a page not indexed by Google?

> **Collection:** Customer Success
> **Last Modified:** 2021-01-05
> **Tags:** Maria, page indexing, rank 99+

Yes it is correct.

Even if it doesn't rank in top 100, we have a process that looks for a landing page, searching with 'site:domain name keywords name' and shows the first link found.
