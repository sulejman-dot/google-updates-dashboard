# ​Search Volume - checking Global values

> **Collection:** Customer Success
> **Last Modified:** 2020-05-11
> **Tags:** Ana, global, search volume

---

For the campaigns that have the set up for google.com without localization, the Search Volume is the global one (only ranks are crawled from new York).

In checking the values in Adwords, remove the location ([https://take.ms/aVNck)](https://take.ms/aVNck) and the values for All locations-global ([https://take.ms/IYUgu)](https://take.ms/IYUgu) will be displayed.
