# How/what can we check when there are "fake Search Volume" cases?

> **Collection:** Customer Success
> **Last Modified:** 2021-03-04
> **Tags:** Fake Search Volumes, impressions, Ioana

---

You make the check in [Google Ads](http://ads.google.com) --> Keyword Planner --> Get search volumes and Forecast 
[https://take.ms/Wfv1V](https://take.ms/Wfv1V)

In [Forecasts](https://ads.google.com/aw/keywordplanner/plan/keywords/forecasts), use 100 for the value and select "exact match" (check this video to learn how - [https://take.ms/g1Rd7](https://take.ms/g1Rd7)). 
It's a high-enough bid to return maximum of impressions.

That should be the Search Volume value for a keyword that displays a notification saying that it's wrongfully aggregated under a certain keyword, so we replaced the Search Volume with another AdWords metric, "the number of monthly impressions that it would get if you would place the maximum bid on it"

!!! Note! This is not the same case as the one with "dangerous keywords" - the ones reporting 0 SV.
