# How to use the Admin Remove LPs option for an account

> **Collection:** Customer Success
> **Last Modified:** 2021-06-30
> **Tags:** account settings, admin, admin options, Delia, distribution, GA, landing page

---

This option skips the specified pages from GA distribution (supports multiple landing pages separated by comma)

If you want to exclude just some specific landing pages, the format should be this way: [https://take.ms/snh0t](https://take.ms/snh0t)

If you want to exclude all the landing pages that contain some specific rules, the format should be this way: [https://take.ms/fIeBq](https://take.ms/fIeBq)

In case you want these changes to be applied retroactively, the campaign needs to be reprocessed.
If the user wants them to be applied from now on, the campaign should NOT be processed.
