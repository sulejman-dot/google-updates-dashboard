# Does Landing Page data update with the timeframe?

> **Collection:** Customer Success
> **Last Modified:** 2021-06-16
> **Tags:** calendar, Ioana, landing page

---

The Landing Page data* displays the current info at any time, even if the keyword was not tracked at the date selected in the calendar.

*referring to the data from the pop-up on the "link/chain" icon, keywords table, Stratgey view
