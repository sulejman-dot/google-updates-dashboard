# Why can't I select "Use YOY search trends" option in Forecast scenario?

> **Collection:** Customer Success
> **Last Modified:** 2020-06-10
> **Tags:** forecast, Ioana, scenario, use yoy trends, YOY, yoy trends

---

Once you've calibrated the Search Volume with YOY for a specific campaign, the "Use YOY search trends" option will automatically be disabled as the your SV already takes into consideration YOY trends
