# Smart Groups don't pull the close variations

> **Collection:** Customer Success
> **Last Modified:** 2020-07-17
> **Tags:** close variant, close variations, Ioana, smart groups

---

The reason behind this behavior - the filter is only applied on the main keywords.

We display the close variations icon next to each main keyword for the user to acknowledge it's part of an aggregation but the close variations are not pulled in the smart group even if they follow the filtering criteria.

For the future redesign of the SEO Campaign section we will revisit the decision and make it all more intuitive.
