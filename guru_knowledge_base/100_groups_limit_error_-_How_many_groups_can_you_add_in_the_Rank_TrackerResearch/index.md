# 100 groups limit error - How many groups can you add in the Rank Tracker/Research?

> **Collection:** Customer Success
> **Last Modified:** 2024-11-26
> **Tags:** 100 groups limit, Delia, groups, rank tracker v2, research, research vault

---

In the Rank Tracker you can add more than 100 groups, but they need to be nested under folders:
[https://help.seomonitor.com/en/articles/5972586-groups-folders-labels-3-levels-of-keyword-grouping](https://help.seomonitor.com/en/articles/5972586-groups-folders-labels-3-levels-of-keyword-grouping)



In the Research (Vault) section we have removed this limit for lists through infinite scrolling of the sidebar.
