- 
Support

  - 
if it’s just a support question

  - 
you provide the solution, an article and/or a workaround.


- 
Bugs

  - 
if a bug is confirmed

  - 
add the Trello task in an internal note in the conversation.


- 
Admin

  - 
for more administrative questions/issues, like invoices, subscription details, etc.


- 
Feature request + priority (nice to have, important, critical)

  - 
on any new feature requests or improvements

  - 
these get sent to ProductBoard, for Cosmin’s evaluation


- 
Demo

  - 
if they request a demo/walkthrough with a BD rep or if they hint at needing one


- 
Feedback

  - 
if they give powerful feedback, be it positive or negative (towards the app or to the support)


- 
Downtime

  - 
if we have any confirmed downtime (with a supporting incident)
