# Pitching campaigns have the default currency set to EUR?

> **Collection:** Customer Success
> **Last Modified:** 2021-02-17
> **Tags:** Ana, currency, pitching

---

Yes, the pitching campaigns use the default currency, which is Euro. 

**But it can be changed by CS** in Website settings - Admin options. Might be necessary to create a new Forecast scenario in order for the change to show.


Otherwise, the currency is determined only through analytics or adobe profile that is connected to the campaign.
