# ​Magnifying glass - My rank and Competitor's rank values

> **Collection:** Customer Success
> **Last Modified:** 2019-06-04
> **Tags:** Ana, competition insights, competitors

---

In the Competition section >> on the magnifying glass >> competitor - common keywords, we have the columns "My rank' and "Competitor's rank'.

'My rank' value is taken from Topics and it's updated weekly. 

'Comp. rank' is the last available rank in Topics (it's doesn't matter when the check is done, here matters when our system has done the crawl).
