When a user is also getting commission (Partner or Affiliate), they get access to a special "[Partner Dashboard](http://take.ms/LbK1f)" in the Settings menu, containing all of the corresponding [details](http://take.ms/7UmEv). 

Each Partner/Affiliate has one or more [promo code](http://take.ms/k4WcP)(s) that will be used by their clients/leads. This promo code needs to be used right when the leads open their SEOmonitor account (and not afterwards). If the code is used at a later date, no retroactive comissions will be issued

_[internal note] If the code is added at a later time and the affiliate/partner asks for a recalculation of the commission due, a maintenance task is to be created (that calls for a script developed by Vali)._

There are 2 ways of claiming the comissions:

1. 
they can **withdraw** it by uploading an invoice in the Partner Dashboard section --> the user has to click the [Withdraw button](http://take.ms/bgHbH) and upload the invoice with the exact value of the Unclaimed Commission. 

1. 
**our recommendation** (and preferred option) for them** **is to opt for getting the [unclaimed commissions as a discount](http://take.ms/Q2oXA) for their future [invoice](http://take.ms/NgLWv)(s); it would be added as "promo credits" through Chargebee.




_[Internal note] all invoices uploaded by our partners are sent to Loredana. She can check if the invoice is correct and can give an estimated date for the payment._
