# How to enable Reporting for clients when Google blocks the add-on

> **Collection:** Customer Success
> **Last Modified:** 2024-02-09
> **Tags:** reporting, Slides add-on

---

Google blocks  some users from installing our Slides Add-on  and don't have Google Business accounts. (**If they have Business accounts,** please see [here](https://app.getguru.com/card/TeAd5kxc/Google-blocks-the-addon-as-being-unsafe-solution?query=slides))

To solve this we can:

1- Access Google Drive by logging in with the integrations account (login [here](https://docs.google.com/spreadsheets/d/1jdJQprbMI2XCCr3nfPSHsI-lZBuonvqlJKmpFgP7N9I/edit#gid=0))

2- Open the SEOmonitor [folder](https://take.ms/CuTcG), create a folder with the name of the client and share the file with the email ([here](https://take.ms/25gAQ))

3- Now they have access and can install the Add-on, following [these](https://docs.google.com/presentation/d/1jcRHR9xfbvjXAS8H0O3mTIG8hT9f8HghUfiP13S8Ipo/edit#slide=id.p1) instructions





The clients should have automatically access to the Google Slides reporting. 

(if there are issues, check if multiple gmail accounts logged in and that they have the extension installed)
