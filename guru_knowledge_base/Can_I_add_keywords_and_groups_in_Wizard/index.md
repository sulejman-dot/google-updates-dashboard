# Can I add keywords and groups in Wizard?

> **Collection:** Customer Success
> **Last Modified:** 2022-06-21
> **Tags:** add, add groups, keywords and groups, upload, wizard

---

Yes, using a CSV with the same formatting as the one used to add keywords&groups in the campaign

[keywords-csv-example.csv](https://content.api.getguru.com/files/view/11b690fe-ade7-4142-862d-3a30882065f9)

The keywords should be in the first columns and the names of the groups in the following columns, on each keyword's line.
You can also add the name of the groups in one column, separated by "," and ";" (soon "|" should become available as well, as this is the delimiter in our exports [https://app.clickup.com/t/2ep5zej](https://app.clickup.com/t/2ep5zej))
