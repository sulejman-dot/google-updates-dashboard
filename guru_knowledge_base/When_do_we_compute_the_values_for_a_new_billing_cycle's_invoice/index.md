# When do we compute the values for a new billing cycle's invoice?

> **Collection:** Customer Success
> **Last Modified:** 2022-03-25
> **Tags:** billing, billing hour, Ioana, next billing

---

**INTERNAL INFO. THE CLIENT SHOULD ONLY BE ADVISED TO ARCHIVE THEIR RESOURCES BEFORE BILLING IS DUE**

We perform a usage update 2h before next billing hour (or 24 hours since last update for safety)

"Next billing hour" can be checked on "subcription details" in ChargeBee, underneath the left sidebar
[https://take.ms/Ma9fE](https://take.ms/Ma9fE)

Usage = active resources + resources archived between the previous subscription renewal and now

Billing date and hour are relative to the moment the subscription was created.
