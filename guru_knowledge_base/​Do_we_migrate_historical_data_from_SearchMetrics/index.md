# ​Do we migrate historical data from SearchMetrics?

> **Collection:** Customer Success
> **Last Modified:** 2018-12-13
> **Tags:** competitors, migrating, migration

---

Yes we do, but before we provide a full promise to the client, please mention this aspect:

_While SearchMetrics migration developments are fully implemented, we have had a particular type of issue with this tool. They are quite demanding in reference to API units, so with your current resources we may not gather all historical data that you currently have with them. They may ask for extra resources when the API calls are done. _

_Should you provide us with the login credentials, we will of course run a test to calculate whether the existent resources are enough, what percentage of data they could cover, or how many resources would be necessary to export all of the existing data._
