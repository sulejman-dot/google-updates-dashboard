# Definition for the API metrics conversion_goals, conversion_goals_rate, conversion_goals_value 

> **Collection:** Customer Success
> **Last Modified:** 2020-11-13
> **Tags:** api, conversions, definition, Ioana, metrics

---

**conversion_goals = conversions**

This is the total number of completed goals.
​
**conversion_goals_rate = conversion rate**

It's the percentage of Conversions/Transactions resulting from the Organic Sessions.
​
**conversion_goals_value = revenue**

It's the Revenue the revenue from transactions generated by  organic visits.

All metrics are relative to the Analytics Goals you selected in Website Settings.
