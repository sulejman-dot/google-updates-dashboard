# How do we localize the SERPs?

> **Collection:** Customer Success
> **Last Modified:** 2024-09-02
> **Tags:** Andreea, location, region ranks, tracking, uule cookie

---

We use the **HL** parameter (for language) and the **GL** one (for location). 

We're also "spoofing" the location using the **UULE** document.cookie to set the location. 

NOT by IP!

Note: this is mostly internal info, but we can share it if clients need to double-check anything.
