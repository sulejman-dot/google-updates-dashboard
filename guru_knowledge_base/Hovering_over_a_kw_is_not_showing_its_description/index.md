# Hovering over a kw is not showing its description

> **Collection:** Customer Success
> **Last Modified:** 2018-05-15
> **Tags:** description, hover

---

It appears that Google did some changes.
There is a new type of video result for which we cannot find any description.
Another issue would be that we display that a kw has SERP video results only when it ranks in top 10 results. 
The tech team confirmed that things will remain like this, since they couldn't find a solution for tracking the description for that type of keyword.
