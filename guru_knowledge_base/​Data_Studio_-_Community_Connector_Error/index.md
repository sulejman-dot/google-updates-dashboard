# ​Data Studio - Community Connector Error

> **Collection:** Customer Success
> **Last Modified:** 2020-04-27
> **Tags:** Ana, data studio

---

It may happen for this error to be displayed to the clients. They would need to click on ok, and to Refresh authorization afterwards (it may need 2 or 3 tries to work).

If the error is a Token one, there was a problem with the added Key (not valid or changed in the meantime). The user would need to Refresh authorization.
