## When to Run

Run this workflow to log an entry to your Second Brain. Trigger with `/journal` or "log to second brain".

## Step 1: Write to Shared Context

Write to `/Users/user/Library/CloudStorage/GoogleDrive-sulejman@seomonitor.com/My Drive/cosmin folder/Shared Context/AI Automation/Daily Checkins/YYYY-MM-DD/Sulejman_{topic-slug}.md`.

Use the following structured template:
- Use Case Category
- What Was Built
- Design Decisions
- Effectiveness
  - Time Saved

## ⚠️ Privacy & Sensitivity Guard
Never log employee data, performance discussions, confidential strategy, legal matters, or customer PII.

## Step 2: Notify User

Notify the user with the exact message: "📝 Logged to your Second Brain: {topic}"
